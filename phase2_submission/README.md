## The core gap

Everything above can be finalized on paper. What cannot be faked is the dataset itself: the
challenge is judged on "the demonstrated dataset as it is submitted" (Technical Evaluation
Criteria) — i.e., real sequences actually synthesized, real purity/MS characterization, and real
toxicity readouts from real human in vitro experiments. As of this draft, no wet-lab data
generation has occurred; `oligotoxdb/data/synthetic/` is explicitly fake data generated by
`oligotoxdb/scripts/generate_synthetic_data.py` for pipeline testing only.

**Before this package can be submitted:**
1. Execute (or contract out) the wet-lab plan in `02_methodology_document.md` — synthesis,
   purification/characterization, and assay panel across the in vitro systems actually used.
2. Ingest real instrument/LIMS output through the existing `oligotoxdb` pipeline
   (`oligotoxdb/oligotoxdb/ingestion.py`) to replace the synthetic CSVs.
3. Rewrite `01_narrative_document.md` sections 1, 2, 4, 5, 6 with real numbers and findings.
4. Confirm `02_methodology_document.md` reflects what was actually done (not just planned).
5. Deposit the real dataset (Zenodo/GEO/PRIDE or equivalent) and fill in
   `dataset/README_raw_data_access.md` with real DOIs/links or attach the real files directly.
6. Export all three text documents to PDF meeting the format rules: 8.5"×11" pages, ≥1" margins,
   ≥11pt Arial, line spacing ≥1.0, no HHS/NIH/NCATS logos or seals.
7. Download and complete the Challenge.gov registration form (Resources tab on the OligoTox
   listing) and include the completed PDF in the submission package.

## Where to submit

Per the Challenge Announcement ("How to Enter"): email the complete package to
**ncatsoligotox@mail.nih.gov** before the Phase 2 deadline (December 31, 2026, 11:59 PM ET).
There is no separate web upload portal — Challenge.gov hosts the listing/registration form only.
